今天一开始我本来打算chill一天把我写的平台deploy了，因为这周二已经超额完成任务了，所以今天就随性一点~  like this:

1：首先，大致的逻辑是这样的：本地运行 → 云服务器 → Docker 隔离 → 域名 → HTTPS → 公开访问

2：所以我做的事情是：把电脑上能运行的 CTF Agent Arena，搬到一台 24 小时联网的服务器上，同时让别人能访问，但又不能让他们上传的 Agent 把服务器搞坏。

但是上面两步还没有做完，我就被布置了新的任务（这个任务的来源就是我周二自己找xu zhengzi和cao zong要的）这个任务就是让我做一个demo的CTF agent, 意思就是相当于当你打开docker，里面可以直接连接一个镜像，这个镜像里面包含了一个AI agent的全部配置。

在此之前，我也检查了一下我之前自己的网站，我这个网站初看好像是比较完善的一个AI实时进化的一个平台，但是细看，觉得我这个网站还是一个比较初级的网站。首先参赛者register并没有提供真正的联系方式就可以register上，感觉验证方式比较水；然后参赛者如果想要上传AI agent的时候似乎只是提供了网址和代码提交的方法，其实感觉大多数还是只是一个format,并不是真正可以操作的镜像，感觉如果落地了还会有很多问题；第三，我觉得我这个网站还有很多题目没有完善，现在看来只有两类题目完善了；第四，这个网站感觉gan的存在只是进化题目，大体还是静态的，并不是随时动态sandbox相互攻防的机制。

所以，前路漫漫啊。。。。

然后今天在改这些的时候，我预习了一下sc1006的一些知识，把前面3-5章节看了一下，但不幸的是我觉得内容太过枯燥，我可能很快就会忘记。然后看了一下sc2001,其中有insert sorting和merge sorting,quick sorting,然后还看了一种基于前缀和的linear sorting,还有就是相对如果数字过大就要用到radix sorting基数排序。

中午还和我爸通了电话，感觉还不错，这是很久以来难得说了一个多小时大家都很平和哈哈哈。今天还是很开心的，只不过我妈还是没有理我。。。www
